ROOT CAUSE

One line of Python

The entire masking system was a single string replacement on the final output. It matched the plaintext flag character for character. Transform the secret into anything else first, and there is nothing left to match.

⚠ VULNERABILITY · /srv/app/app.py line 47
45 raw_output = subprocess.check_output(cmd, shell=True)
46 raw_output = raw_output.decode("utf-8")
47 masked_output = raw_output.replace(REAL_FLAG, "***[MASKED_SECRET_FLAG]***")
48 return jsonify({"output": masked_output})
str.replace() matches the exact plaintext only. Any encoding, slicing, or transformation produces a string that never matches — and is never masked.

How commands got in

The POST /api/v1/trigger endpoint accepts a commit_message field and interpolates it into a shell echo command without sanitisation. Command substitution runs freely inside it.

TECHNIQUES

Two paths to the same flag

Both routes exploit the same masker flaw. The hex route recovered the flag in a single run. The slicing route required joining across multiple runs — slower, but it confirmed the result.

A
Hex encode · 1 run

xxd converts the flag to ASCII hex before the output is returned. The masker sees only hex digits — no plaintext match.

commit_message=x $(echo -n $FLAG | xxd -p)
hex string in log → decode with xxd -r -p → flag
B
Slice & join · N runs

Parameter expansion cuts the flag into short substrings. Each piece is shorter than the full secret and never matches the replace pattern.

commit_message=x ${FLAG:0:8} commit_message=x ${FLAG:8:8} commit_message=x ${FLAG:16:8} ...
collect slices from runs #1081–#1104 → join in order → flag

REMEDIATION

Three things that fix this

FIX 1
Never put the secret in the shell environment

If $FLAG is not an env var available to user-controlled commands, it cannot be read regardless of masking. Inject secrets only into the specific steps that legitimately need them, in isolated contexts.

FIX 2
Never interpolate untrusted input into a shell string

Pass commit_message as an element in an argument list — subprocess.run(["echo", commit_message]) — not as part of a shell string with shell=True. Command substitution cannot run inside a plain argument.

FIX 3
Mask every encoding of the secret, not just the plaintext

If masking must be used, check output against the hex, base64, URL-encoded, and reversed forms of the secret — and reject any output that contains a substring of the secret above a minimum length threshold.
